# Quantifying Denoising Thresholds for Mayan Hieroglyphic Images with Convolutional Autoencoders

**Authors:** Valeria Durán-Rubio and Edgar Román-Rangel  
**Institution:** Instituto Tecnológico Autónomo de México (ITAM), Mexico  
**Research area:** Computer vision, cultural heritage, image restoration, deep learning

## Overview

This repository contains the Python notebooks developed for the study *Quantifying Denoising Thresholds for Mayan Hieroglyphic Images with Convolutional Autoencoders*.

The research investigates the robustness of convolutional denoising autoencoders under different types and intensities of synthetic image degradation, focusing on identifying empirical noise-tolerance thresholds for Mayan hieroglyphic images.

Rather than focusing exclusively on reconstruction quality, the study evaluates when denoising remains effective and when increasing degradation leads to substantial information loss.

Two main degradation scenarios are examined:

1. **Structured occlusion noise:** localized square patches that remove portions of glyph strokes.
2. **Salt-and-pepper corruption:** spatially distributed pixel perturbations at different corruption intensities.

Reconstruction quality is evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), Peak Signal-to-Noise Ratio (PSNR), and Structural Similarity Index (SSIM).

## Dataset

The experiments use 1,280 Mayan hieroglyphic images derived from the AJIMAYA project of the Instituto Nacional de Antropología e Historia (INAH), Mexico.

The images are converted to grayscale, resized to 64 × 128 pixels, and binarized to emphasize glyph stroke structure.

## Experimental methodology

### 1. Image preprocessing

The preprocessing workflow includes grayscale conversion, spatial normalization to 64 × 128 pixels, and binarization.

The models use normalized single-channel image arrays, with clean images serving as reconstruction targets.

### 2. Structured occlusion experiments

Structured corruption is generated by replacing localized square regions with white pixels.

The experiments consider:

- Number of patches: 2, 3, 4, and 5.
- Patch half-width parameters: 10, 20, and 30 pixels.
- Corresponding nominal square dimensions: 21 × 21, 41 × 41, and 61 × 61 pixels.
- Total experimental configurations: 12.

Patch placement is randomized. The notebook contains the implementation used to generate the corresponding corrupted image arrays.

### 3. Diffuse noise experiments

The diffuse-corruption experiments use pixel-level perturbations stored in precomputed image arrays.

The historical experiment files correspond to noise factors of **0.20, 0.39, and 0.60**. The intermediate factor is approximately 0.40.

Some original file and variable names retain the term `gauss` for compatibility with the experimental workflow. These names should not, by themselves, be interpreted as a definition of the noise distribution.

### 4. Autoencoder architectures

Two convolutional denoising autoencoder configurations are examined:

**Compact model**

- 185,217 trainable parameters.
- Convolutional encoder–decoder architecture.
- ReLU hidden activations.
- Sigmoid output activation.
- Dropout regularization.

**High-capacity model**

- 3,099,137 trainable parameters.
- Deeper convolutional encoder–decoder architecture.
- ReLU hidden activations.
- Sigmoid output activation.
- Dropout regularization.

### 5. Training and evaluation

The recovered training notebooks use the following settings:

| Parameter | Configuration |
|---|---|
| Optimizer | Adam |
| Training loss | Mean Squared Error (MSE) |
| Batch size | 32 |
| Training epochs | 50 |
| Input size | 64 × 128 × 1 |
| Evaluation metrics | MAE, MSE, PSNR, SSIM |

The archived experiments use a held-out subset as the validation dataset during training. The MAE summaries for the structured-noise experiments were obtained from the final validation epoch. This evaluation procedure should be considered when interpreting the reported results.

## Reproducing the experiments

The notebooks depend on image arrays generated during the original research. These arrays are not distributed through this repository because of dataset restrictions.

To reproduce the workflow, authorized users must obtain the required images and prepare the corresponding local data files.

The intended experimental sequence is:

1. Prepare and normalize the image dataset.
2. Generate structured or diffuse corrupted inputs.
3. Train the relevant denoising autoencoder.
4. Evaluate reconstruction performance against the clean image targets.
5. Analyze reconstruction metrics across noise configurations.

The supplied notebooks preserve the experimental code and expected input conventions. They are not currently a fully self-contained reproduction package because restricted datasets and some original preprocessing components are not distributed.

## Research context

The study examines how restoration performance changes with noise severity and image characteristics, including glyph stroke density.

Its primary contribution is an empirical analysis of denoising robustness under distinct degradation conditions, identifying operating ranges where reconstruction remains comparatively effective and settings where reconstruction error increases substantially.
